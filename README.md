# Yggdrasil-VTT

**Yggdrasil-VTT brings your game nights online.**

For me the charm of tabletop games are the home rules and the leniency you can afford newer or unlucky players. This is something that tends to get lost in translation, when turning any tabletop game into an online format. Yggdrasil is my take on solving these issues.

## So, what is Yggdrasil
Yggdrasil is a game IDE, meaning it is an environment where the user can create and run their own games, building each game up from a collection of small modular systems, where you define how each piece interacts and what makes each piece different, before inviting friends and family to an online playtest. Alternatively, you can download user created takes on games and adjust these takes to better fit home rules, then run an online session.

Differing from traditional online games, a session on Yggdrasil generates a _guideline timeline_, meaning the Yggdrasil engine will run the game as instructed and generate a timeline of changes based on player actions, but this timeline can be altered allowing the host of the game to overrule outcomes, in the case of scripting oversights or culinary incentives (DM taxes). The game will then recalculate the timeline, as long as the overruling doesn’t change the flow of logic.
